Frequently Asked Questions

Everything you need to know about how JAMES works, privacy guarantees, hardware requirements, and capabilities.

Is JAMES free to use?

Yes, JAMES is completely free. No account, no subscription, no API key required. It is open-source under the MIT License.

Does JAMES send my messages to a server?

No. All AI inference runs locally in your browser using WebGPU or WebAssembly (WASM). Your messages never leave your device unless you explicitly use a tool that fetches external data (like weather or Wikipedia lookup).

Does JAMES work offline?

Yes. After the model weights are downloaded once and cached, JAMES works completely offline. The app can also be installed as a Progressive Web App (PWA) for a native-like offline experience.

What AI models does JAMES use?

JAMES automatically selects the best model for your hardware from a range including Qwen2.5 0.5B, SmolLM2 1.7B, Llama 3.2 1B, Llama 3.2 3B, DeepSeek R1 1.5B, Phi-3.5 mini 3.8B, and Gemma 2 2B. GPU models run via WebGPU; CPU fallbacks use WASM.

What browser do I need?

Chrome 113+ or Edge 113+ is recommended for WebGPU acceleration. Firefox works via WebAssembly (WASM). Safari has limited WebGPU support.

Is JAMES open source?

Yes. JAMES is open source under the MIT License. The full source code is available on GitHub.

Can JAMES run Python code?

Yes. JAMES includes an in-browser Python execution engine powered by Pyodide (a WebAssembly port of CPython). You can run real Python code including NumPy, math, and algorithms entirely in the browser.

Does JAMES do math and physics?

Yes. Alongside Python, JAMES features native, zero-dependency tools for calculating special relativity, particle physics (like Compton scattering), linear algebra (eigenvalues, Gram-Schmidt QR), and differential equations directly in the browser.

Can JAMES generate art?

Yes, JAMES features a mathematical generative art engine that procedurally generates retro 8-bit symmetrical pixel art (like space invaders or Github identicons) using pure JavaScript and renders them instantly as SVGs in the chat.

Is JAMES a ChatGPT alternative?

JAMES is a free, private, offline-capable ChatGPT alternative that runs entirely in your browser with no account or API key. Unlike ChatGPT, your data never leaves your device.

Does JAMES store chat history?

Yes. Chat history is stored locally in your browser using high-performance, asynchronous IndexedDB storage. It never leaves your device and can be cleared at any time.

Can JAMES notify me when it finishes thinking?

Yes! If you are generating a long response or downloading a large model and you minimize your browser or switch tabs, JAMES can send a smart Desktop Notification to let you know it's ready.

Does JAMES have sound?

Yes! JAMES features a zero-dependency Web Audio API sound engine that plays satisfying retro-style chimes when messages are sent or received, and when a model successfully loads into the GPU.
